# 六位验证码与唯一默认昵称

注册及忘记密码使用六位数字验证码，前后端均只接受六位；登录仍使用邮箱和密码。Supabase Email OTP length 配置为 6，发送间隔与有效期保持现有设置。切换后，旧的八位验证码应重新获取。

默认昵称格式为「交易员XXXX」，编号范围 1000–9999，最多支持 9000 个同时使用的默认昵称。数据库保存已分配的昵称，刷新、退出再登录不会重新生成。数据库唯一约束防止同时注册分到同名；在个人中心修改昵称时也不能占用其他账号正在使用的昵称。编号用完时明确报错，不生成重复昵称。

原来为空或「研究员」的默认昵称改为随机昵称；已有自定义昵称保留。分配只面向已经确认邮箱的账户，未确认注册不占用默认昵称。昵称通过服务器核验身份后读取及修改，浏览器不能直接分配或写入其他账户的昵称。

部署时先执行新增 Supabase 昵称迁移，再发布网站代码。数据库测试使用事务并回滚，不保留测试账户。
