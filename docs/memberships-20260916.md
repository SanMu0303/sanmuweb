# 手动会员管理（2026-09-16）

管理员在 `/admin/members/` 搜索邮箱或昵称，选择已验证邮箱的用户，设置北京时间的到期日期并保存。所选日期当天 23:59:59 到期。可快捷增加 30、90、365 天：有效会员从当前有效到期时间延长，其余用户从当前时间起算。撤销后立即停止签发新的会员资源链接；可以再次设置未来期限重新开通。

会员状态独立于注册、登录和管理员角色。新旧普通账号没有会员记录时均为 `none`；本次迁移不会自动开通任何账号。不支持永久会员，暂不包含支付或自动续费。

## 服务端权限

每次读取内容权限时，服务端重新读取数据库会员状态。数据库仅在未撤销且 `expires_at` 晚于数据库当前时间时返回 `active`；网站另检查有效到期时间。管理员按服务端 `ADMIN_EMAILS` 配置判定，会员开通不会修改 Supabase Auth 的管理员角色或用户元数据权限。

管理 API 先验证当前登录者的管理员身份，保存服务再次检查管理员邮箱。数据库 RPC 校验操作者身份及目标邮箱已确认；所有 RPC 仅允许 `service_role`，固定空 `search_path`。会员表和审计表启用 RLS，浏览器角色没有直接读写权限。数据库故障时拒绝放行。

保存必须携带当前 `revision`；同一用户的并发编辑由事务锁和版本校验处理，过期版本返回冲突并要求刷新。开通、续期、撤销均记录操作者、旧新到期时间、旧新撤销时间与版本。审计保留账号 ID 快照，账号删除不会清空审计历史。

## 媒体访问边界

文章正文、会员图片及自托管会员视频由服务端检查权限。会员图片和自托管视频的已签发链接最长仍可使用 60 秒，并受会员剩余有效秒数限制；已下载或已缓存的数据无法收回。撤销会员不会即时撤销已签发的存储链接。

YouTube、Bilibili 等第三方公开视频的原始链接仍由第三方控制，网站会员判断只能限制本站展示入口，不能阻止访问已知的公开地址。需要限制原始文件访问的会员视频应上传到本站私有存储。
